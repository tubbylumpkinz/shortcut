About

A notebook, not a brand.

Shortcut collects the small things that make being online less annoying: a keystroke, a better tool, a link that earns a permanent tab. Nothing here is written to go viral.

What this is

A running notebook. Some posts are essays about a habit; some are lists of links with a sentence of justification. The common thread is that everything has been used, not just read about. If a tool breaks or stops being good, it leaves the library.

The site is deliberately small. It loads in a second, has no cookie banner because it sets no cookies, and does not know who you are. The only thing it remembers is whether you prefer light or dark — and that stays in your browser.

The rules

  • No affiliate links. Nothing on this site pays us to be here.
  • No sponsored posts. If that ever changes, it will be labelled in the first line, not the footer.
  • Test before recommending. A link needs a real use, not a nice landing page.
  • Cut, don't pad. A list of thirty links means thirty that survived, not thirty that were easy to find.
  • Corrections get a date. When something is wrong, it is fixed and noted, not quietly edited.

Colophon

Plain HTML, one CSS file, and about four hundred lines of vanilla JavaScript. No framework, no build step, no package manager. The post list and link library live in a single data file, so adding an entry is a copy-paste job rather than a deployment.

Type is Instrument Serif for display, Inter for text, and JetBrains Mono for labels. The palette is warm paper and ink, with a single orange accent that exists mostly to point at things. The grain is one inline SVG.

Hosting is static, which is another way of saying the whole site is a folder. It will still work in ten years on any web server, which is more than most blogs can promise.

Say hello

Corrections, better links, and strong disagreements are all welcome: hello@shortcut.blog. If you send a tool, say what you use it for — that is the part that gets it filed.
